비밀번호를 넣으세요. 이 기기에서는 다음부터 다시 묻지 않습니다.

관리자용: GitHub 토큰으로 연결

글 목록

고칠 글을 누르거나, 새 글을 직접 쓰세요.

글 수정

사용법 — 처음이시면 눌러 보세요

1. 이 화면을 휴대폰 첫 화면에 두기

  • 아이폰: 아래 가운데 [공유] → [홈 화면에 추가]
  • 갤럭시: 오른쪽 위 [⋮] → [홈 화면에 추가]
  • 비밀번호는 이 기기에서 한 번만 넣으면 됩니다.

2. 새 글 쓰기

  1. [+ 새 글 쓰기]
  2. 제목: 지역 + 무엇 (예: 제천 독채 펜션, 겨울에도 따뜻한가요?)
  3. 요약: 이 글의 답을 한두 문장으로. 검색 결과에 그대로 보입니다.
  4. 태그: 쉼표로 (예: 제천펜션, 제천독채펜션)
  5. 본문: [소제목]은 질문으로, 바로 아래 첫 문장에 답을 적으세요.
  6. [저장] → 1~2분 뒤 홈페이지 블로그에 올라갑니다.

3. 쓴 글 고치기

  • 위 글 목록에서 글을 누르거나
  • 홈페이지 블로그 글을 보다가 오른쪽 아래 「이 글 수정」을 누르세요.

4. 사진

  • 넣기: 넣을 자리를 한 번 누르고 → [사진 넣기]. 여러 장 한 번에 됩니다. 크기는 자동으로 줄어듭니다.
  • 빼기: 사진을 눌러 빨간 테두리가 생기면 → [고른 사진 빼기]

5. 검색에 잘 걸리는 요령

  • 숫자로 쓰기 — 가격, 시간, 인원, 거리
  • 실제 사진 쓰기, 지어낸 후기 쓰지 않기
  • 글 하나에 주제 하나

6. 실수했을 때 · 안 될 때

  • 방금 한 것 취소: [되돌리기]. 저장 전이면 [목록]으로 나가면 바뀐 것이 버려집니다.
  • 「저장 실패」: 인터넷을 확인하고 [저장]을 다시 누르세요.
  • 저장했는데 안 바뀜: 1~2분 기다린 뒤 홈페이지를 새로고침(휴대폰은 아래로 당기기)
  • 비밀번호가 안 맞음: 관리하는 분께 새 비밀번호를 받으세요.

7. 비밀번호 관리 (관리하는 분)

  • 비밀번호는 카톡 단체방에 올리지 마세요.
  • 직원이 그만두면 글 목록 위 [비밀번호 정하기·바꾸기]로 바꾸세요. 그러면 모든 사람이 새 비밀번호를 넣어야 합니다.
  • 바꿀 때는 이 홈페이지 전용 GitHub 토큰이 한 번 필요합니다. 모르시면 만든 곳에 문의하세요.
